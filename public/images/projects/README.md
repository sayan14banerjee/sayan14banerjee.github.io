# Project screenshots

Add your real project screenshots in this folder. The portfolio loads these exact filenames:

- `nexora-ai.png`
- `nexora-docs.png`
- `streamsphere.png`
- `nexora-interview.png`
- `ai-developer-agent.png`
- `expense-tracker.png`

Use PNG, JPG or WebP and update the matching path in `src/App.jsx` if you choose a different filename or extension. Recommended: landscape screenshots at 1200 × 800 or larger. Keep screenshots free of secrets, API keys and private user data.
